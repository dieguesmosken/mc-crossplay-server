Um mundo, qualquer aparelho.

Servidor de Minecraft onde quem joga no PC (Java) e quem joga no celular ou console (Bedrock) entra no mesmo mundo.

Como entrar

Java Edition

Multijogador, adicionar servidor, endereço:

server.teuzin.com.br

Bedrock Edition

Servidores, adicionar servidor. Endereço e porta:

server.teuzin.com.br

Porta 19132

Os endereços ainda estão em testes e podem não responder. A fila de espera e a lista de quem está online chegam numa próxima versão.

Sobre o projeto

É um servidor feito para amigos, rodando num computador em casa. Ele junta as duas versões do Minecraft com o Geyser e o Floodgate, então ninguém precisa comprar a outra edição para jogar junto.

O código é aberto e está no GitHub: dieguesmosken/mc-crossplay-server.
